# Checklist LGPD para IA no WhatsApp

Checklist publico da XMACNA para empresas que querem usar agente de IA para WhatsApp, vendas, atendimento e qualificacao de leads com mais controle de privacidade.

O objetivo e transformar LGPD em rotina operacional: finalidade clara, base legal, transparencia, minimizacao de dados, seguranca, retencao e canal de direitos do titular.
